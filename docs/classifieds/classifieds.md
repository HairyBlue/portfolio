## 5. Architectural Paradigms & Core Disciplines

- **Vertical Slice Architecture:** Organizing codebases by domain features rather than horizontal technical layers, ensuring clean boundaries and maintainable expansion.
- **Agentic Engineering & Orchestration:** Authoring declarative memory files (`AGENTS.md`), multi-agent calibration (`ACON`, `herdr`), zero-token reactive waiting, and worktree isolation.
- **Data Pipeline Architecture (ETL):** Ingesting, cleaning, normalizing, and reconciling massive datasets with high throughput and data integrity guarantees.
- **Defensive Engineering & Zero-Overengineering:** Strict compliance with the 7-Rung Decision Ladder (YAGNI → Codebase Reuse → Stdlib → Native APIs → Zero New Dependencies → Inline Clarity → Minimum Working Diff).
- **Design Systems Craft:** Zero-slop bespoke aesthetic engineering using Vanilla CSS custom properties, warm coffee palettes (Latte, Mocha, Espresso, Cream), and typographic rhythm.
